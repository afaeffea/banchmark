Ограничение частоты

Общее на весь прогон: при работе через роутер лимит считается по ключу, а не по модели. 0 — не ограничивать. Пауза троттлинга не попадает в замер латентности.

Массовое переключение

Проставить один base_url и одну переменную ключа всем моделям сразу — удобно при переезде на роутер или обратно на прямые API.
Значения читаются и пишутся в .env (файл в .gitignore). Панель слушает только 127.0.0.1.
